## Project Overview

This assignment analyses the HR Analytics: Job Change of Data Scientists dataset to identify and address data-quality issues. The analysis covers missing values, outliers, duplicate records, inconsistent formats, personally identifiable information (PII), and potential bias risks.

## Dataset

- **Source:** Kaggle — HR Analytics: Job Change of Data Scientists
- **URL:** https://www.kaggle.com/datasets/arashnic/hr-analytics-job-change-of-data-scientists
- **File used:** `aug_train.csv`
- **License:** CC0: Public Domain

## Instructions to Run

The notebook can be executed using **GitHub Codespaces, Google Colab, or Jupyter Notebook**.

### Option 1: GitHub Codespaces

1. Open this GitHub repository.
2. Click **Code → Codespaces → Create codespace on main**.
3. Wait for the Codespace environment to open in VS Code.
4. Open `TTTC3213_Assignment1.ipynb`.
5. Ensure the Python and Jupyter extensions are installed.
6. Install the required libraries if they are not already available:
   ```bash
   pip install pandas numpy matplotlib seaborn ipykernel
   ```
7. Select the Python kernel and click **Run All**.
8. Review the generated outputs, visualisations, and conclusions.

### Option 2: Google Colab

1. Open Google Colab
2. Select **File → Open notebook → GitHub**.
3. Enter the repository URL and open `TTTC3213_Assignment1.ipynb`.
4. Upload `aug_train.csv` through the Files sidebar.
5. Select **Runtime → Run all**.

### Option 3: Jupyter Notebook (Local)

1. Clone or download this repository.
2. Install Python and the required libraries.
3. Open `TTTC3213_Assignment1.ipynb` using Jupyter Notebook or JupyterLab.
4. Ensure `aug_train.csv` is in the same directory as the notebook.
5. Run all cells sequentially from top to bottom.
